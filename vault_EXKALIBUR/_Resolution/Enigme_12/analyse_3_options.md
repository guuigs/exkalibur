## Verdict
- **C (loup / Tire-Loup) : ÉLIMINÉE.** Trois réponses de l'auteur l'excluent :
  - hors des 1 % (1 871 m) ;
  - coffre accessible en fauteuil (FAQ03-112), alors que le ruisseau est 80 m plus bas dans une gorge à plus de 100 % de pente ;
  - départ imposé au rempart (FAQ06-166).
  - De plus, « Tire-Loup » est un jeu de mots français, alors que les symboles de l'enl. 9 sont un « code universel » (FAQ06-138).
- **B (Couvat) : ~10 %.** Atouts : visible, ensoleillé tôt, croisée pile à 10 stades. Mais le seul ruisseau proche longe les maisons de deux hameaux : le coffre serait près de bâtiments (FAQ05-107).
- **A (Bretonnières) : ~25 %.** C'est la seule option qui satisfait à la fois l'éloignement des bâtiments, l'accessibilité, la clairière ancienne et une eau « merveilleuse » (cascade de tuf). Ses faiblesses :
  - invisible depuis le rempart, et c'est la plus importante ;
  - pas de croisée visible dans le pré ;
  - soleil tardif au fond de la gorge.
- **Reste ~65 %** : une autre zone, ou un départ ailleurs.

## Les signes du ciel de l'enluminure 9 face aux zones
Les faits : lecture de gauche à droite (FAQ05-019) ; on les comprend une fois la zone trouvée (06-067) ; « code universel », identique dans toutes les langues (06-138) ; pas un rébus phonétique (06-059) ; les paires se lisent ensemble (07-143) ; ils servent à identifier « un élément crucial » (07-134), à avoir un « déclic » (07-198) ; ils sont distincts du reste de l'image (06-222) ; l'ancre est l'avant-dernière étape (06-181) ; « de l'ancre au dernier symbole, il faut traverser l'arbre » (06-226) ; le 6e est un croissant de lune (06-258).

1. **Noms de lieux** : sur les 671 lieux-dits, aucun ne contient étoile, arc-en-ciel, âne, émeraude, diamant, ancre ou lune à moins de 2,5 km. Seul « Tire-Loup » colle, mais c'est du français, ce que la FAQ06-138 rend peu probable. **Négatif pour les trois zones, comme attendu.**
2. **Lecture comme une suite d'étapes** (hypothèse) : six signes pour six étapes du texte, dans l'ordre.

| Signe | Étape du texte proposée |
|---|---|
| loup | l'aube au rempart (« dernière veille… au matin ») |
| étoile | l'astre glorieux, le soleil est une étoile |
| arc-en-ciel | eau + lumière : le ruisseau « magnifié », ou les embruns d'une cascade au soleil |
| âne + émeraude | la clairière verte et ses chemins |
| diamant + ancre | la grande roche, qui « bloque », point fixe et avant-dernière étape (06-181) |
| (arbre) | la souche-majesté, qu'on « traverse » (06-226) |
| croissant | le coffre (l'auteur l'a enterré la nuit, FAQ06-213) |

   Dans cette lecture, seul l'**arc-en-ciel** dépend du lieu. Il faut de l'eau en embruns sous le soleil du matin. **A est la seule des trois zones avec une cascade** (de tuf). C'est un léger plus pour A, à vérifier sur place.
3. **Piste à creuser (non testée)** : « code universel » pourrait désigner **Unicode** (Universal Coded Character Set). Les six dessins existent tous comme caractères Unicode : 🐺 ⭐ 🌈 🫏 💎 ⚓ 🌙. Leurs numéros (codes) pourraient donner des nombres, une fois la zone connue.
