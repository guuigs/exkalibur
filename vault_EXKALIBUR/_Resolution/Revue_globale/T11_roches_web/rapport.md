## 4. Récits et légendes locales recensés

1. **Tour d'Avalon / Hugues d'Avalon (saint Hugues de Lincoln, 1140-1200)** — tour des chartreux (1895) sur le donjon du château d'Avalon (Romestang d'Avalon, avant 1049). Hugues, fils d'Anne de Theys et Guillaume Romestang, éduqué à Villard-Benoît, diacre de Saint-Maximin, entre à la Grande Chartreuse (1163), évêque de Lincoln (1186). Légende du cygne blanc (Angleterre). **Aucune roche/souche/clairière/ruisseau locale** dans la biographie.
2. **Cascade de la Pierre Tombante** — « la commune [La Chapelle-du-Bard] est limitée par le ruisseau du Buisson, qui forme la cascade de la Pierre Tombante » (Wikipédia). Ruisseau + cascade attestés.
3. **Réseau pédestre du Grésivaudan** — réseau de carrefours pédestres numérotés (système « points-nœuds ») ; le nœud « La Pierre Tombante » est un carrefour = « la jonction des chemins ».
4. **Sept merveilles du Dauphiné** (Gervais de Tilbury, XIIIe s.) : mont Aiguille, Fontaine ardente, tour sans Venin, Cuves de Sassenage, Grottes de la Balme, Pont Lesdiguières, **Pierre Percée** (+ Manne de Briançon, Pierres ophtalmiques de Sassenage). Roches légendaires, hors zone.
5. **Pierre à cupules de Saint-Hilaire-du-Touvet** — bloc erratique à ~100 cupules (néolithique), plateau des Petites Roches (Grésivaudan, Chartreuse) ; hypothèses « pierre à sacrifice / carte du ciel / site funéraire ». Roche légendaire la plus proche.
6. **Chaise du Seigneur / Fromage de Gargantua** (Chozeau, Isère) — bloc erratique à cupules, légende gargantuesque, MH 2007.
7. **« roche qui sonne » / « roche branlante »** — **aucune** attestée dans le Grésivaudan/Saint-Maximin ; seul rocher à connotation instable = « La Pierre Tombante » (qui tombe).

## 5. Contraintes techniques rencontrées

- `web_search` et `web_extract` (backend Firecrawl keyless) : **403 Forbidden** — inutilisables.
- DuckDuckGo : captcha ; Bing : page sans résultats organiques ; Mojeek : 403 ; SearX : bloqué.
- Overpass principal : « server too busy »/timeout ; **OSM API principale + Nominatim + Wikidata + open-elevation + API Wikipédia fonctionnels**.
- API Wikipédia : 429 (rate-limit) — contourné par backoff.

**Conséquence** : aucune légende écrite *spécifique* à « La Pierre Tombante » n'a pu être confirmée par un moteur de recherche ; l'identification repose sur OSM/Wikidata/Wikipédia, sources primaires fiables.
